# CAIO / Practice

Сайт практики для руководителей, которые создают и развивают AI-функцию в компании. Консультации и совместная работа помогают связать бизнес-задачи, архитектуру, внедрение и команду. Основной регион — Беларусь; дополнительный — Россия. Команда находится в Минске.

Сайт: [genai.by](https://genai.by)

## Языковые версии

- Русская версия: [genai.by](https://genai.by/).
- Белорусская версия: [genai.by/be/](https://genai.by/be/).

Обе версии содержат главную, каталог и все 40 публикаций. Переключатель RU / BE открывает ту же страницу на другом языке и сохраняет якорь текущего раздела. Белорусская навигация ведёт на страницы внутри `/be/`; стили, JavaScript, шрифты и изображения остаются общими.

Белорусские страницы — статические HTML-файлы в `be/`, без отдельной сборки и зависимости от JavaScript для чтения или переключения языка. При изменении текста обновляйте соответствующую страницу на втором языке, метаданные, каталог и `publications/manifest.json` в обеих версиях. Сохраняйте одинаковые slug и ID разделов, чтобы переключение языка и якорные ссылки продолжали работать.

Каждая индексируемая страница содержит свой canonical и взаимные ссылки hreflang (`ru`, `ru-BY`, `be`, `be-BY`, `x-default`). Общий sitemap включает 84 адреса. В `be/` также находятся локализованные JSON-LD, источники для LLM, webmanifest и страница 404. Обработчик корневой 404 выбирает белорусский текст для неизвестных адресов в `/be/`, сохраняя запрошенный URL.

Проверка перед публикацией:

```sh
node --test tests/*.test.mjs
python3 scripts/build-discovery.py --check
```

Проверки охватывают исходный контент, языковые пары, ссылки и ресурсы, якоря, каталог, даты и источники статей, метаданные и поведение мобильного меню, а также согласованность HTML, JSON-LD и текстовых источников для LLM.

## SEO, география и AI-поиск

Беларусь остаётся основным регионом сайта. Работа с руководителями и командами из России указана в видимом содержимом обеих главных и в `Service.areaServed`. Общие языковые альтернативы `ru` и `be` дополняют `ru-BY` и `be-BY`: русскоязычным читателям из России доступна та же каноническая русская версия. Отдельных дублирующих страниц для регионов нет.

Все 84 индексируемые страницы доступны в статическом HTML, имеют собственный canonical, взаимные языковые альтернативы и разрешают большие изображения в поисковых превью. Страницы 404 исключены из sitemap и закрыты от индексации. `lastmod` отражает изменение страницы, включая значимые изменения ссылок и структурированных данных; даты первоначальной публикации статей сохраняются.

Данные главных в `ai.json` точно повторяют их inline JSON-LD. Контакт Вадима Владымцева — [vadimohka.ru](https://vadimohka.ru/); этот же адрес используется для идентификации автора в разметке публикаций. Вопросы и ответы в JSON-LD соответствуют видимому FAQ. Ссылки `citation` берутся из существующих источников статей, авторство и атрибуция адаптированных материалов сохраняются.

### Поддержка источников для LLM

`llms.txt` — краткий указатель по практике и публикациям. `llms-full.txt` содержит тексты главной и всех 40 статей с авторами, первоначальными датами и ссылками на источники. Белорусские версии находятся в `be/`. Файлы генерируются из видимого HTML и каталога, без отдельной редакционной копии, скрытых адресов или искусственных дат обновления:

```sh
python3 scripts/build-discovery.py
python3 scripts/build-discovery.py --check
```

После изменения HTML или каталога перегенерируйте файлы и сохраните их вместе с исходными изменениями. Проверка `--check` отклоняет рассинхронизацию. Скрипт использует только стандартную библиотеку Python 3; сборщик сайта и внешние пакеты не требуются.

`robots.txt` разрешает обход всем роботам, включая поисковых и AI-ботов. Дополнительные текстовые файлы помогают системам, которые их используют, но не гарантируют индексацию, цитирование или рост позиций. Google не использует `llms.txt` как фактор ранжирования. Структурированные данные и обычный HTML остаются основными источниками фактов.

## Оформление

Нейтральное оформление сочетает белый фон `#ffffff`, графитовый текст `#171719`, светло-серые поверхности `#f4f5f7` и синий акцент `#3558e8`. Синий выделяет основные действия, ссылки и текущий язык; тёмные блоки используют графит вместо зелёного. Главная, каталог, статьи и страницы 404 используют общие навигацию, подвал и визуальные принципы. Общие стили находятся в `assets/css/styles.css`, стили публикаций — в `assets/css/publications.css`, переключателя языков — в `assets/css/languages.css`.

Фон первого экрана `assets/img/practice-workspace.webp` — оригинальное декоративное изображение, сгенерированное AI через встроенный Imagegen. Размер — 1536 × 1024 пикселя, вес — 49 186 байт (около 48 KiB). Изображение преобразовано в WebP для быстрой загрузки.

Краткий замысел изображения: современная комната для совместной работы со стеклянными перегородками, столами и чистой доской; холодный дневной свет справа, глубокие графитовые тени слева; без людей, надписей, логотипов и компьютерных интерфейсов. Оно служит декоративным фоном и не изображает реальный офис практики.

Существующий знак перекрашен через Imagegen в серебристо-графитовую палитру с небольшими синими отражениями. Сохранены переплетённые ленты и чёрная подложка. Из одного мастера подготовлены favicon, иконки приложения и изображение для превью ссылок; реальные портреты экспертов не менялись.

## Публикация

GitHub Pages публикует статические файлы при обновлении `main` или ручном запуске workflow. Перед публикацией выполняются контрактные тесты и проверка актуальности источников для LLM; при ошибке публикация останавливается. В артефакт `_site` попадают только файлы сайта: каталоги `tests` и `scripts`, настройки GitHub и служебные Markdown-файлы исключены. Тесты и генератор остаются в репозитории.
